Hardware Glossary (For Beginners)

RIP (Instruction Pointer): Think of this as the CPU's "reading finger". It highlights the exact line of code it is currently executing in the read-only Code Segment. It jumps around when it hits a while loop or an if statement.

RSP (Stack Pointer): Think of this as the memory bookmark. It tracks the "top" of your available RAM. It moves up to reserve space for variables, and it violently snaps back down to instantly destroy them when a function ends.
